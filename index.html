Setup Guide
  1. 1เปิด script.google.com → New Project (หรือเปิดโปรเจกต์เดิม)
  2. 2ลบ code เดิมทั้งหมด → Paste → Ctrl+S
  3. 3เลือก savePDFFromGmail → ▶ Run เพื่ออนุญาตสิทธิ์ (มีสิทธิ์ใหม่ "เชื่อมต่อบริการภายนอก" ไว้โหลดตัวปลดล็อค PDF)
  4. 4ตั้ง Trigger → savePDFFromGmail → Time-driven → Every hour
  5. 5มี PDF ติดรหัสอยู่ใน Drive แล้ว? เลือก unlockExistingFiles → ▶ Run ครั้งเดียว — ไฟล์ติดรหัสจะถูกแทนด้วยไฟล์ปลดล็อค (ไฟล์เดิมไปอยู่ในถังขยะ กู้คืนได้ 30 วัน)
  6. 6เสร็จสิ้น 🎉 ระบบจำไฟล์ที่เคยบันทึกไว้ใน Script Properties แม้จะลบไฟล์ออกจาก Drive ก็ไม่โหลดซ้ำ
💡 ถ้าอัปเดตจากเวอร์ชันเดิม: ชื่อฟังก์ชันและประวัติยังเหมือนเดิม Trigger เดิมใช้ต่อได้ ไฟล์ที่เคยเซฟแล้วจะไม่ถูกโหลดซ้ำ — แต่ต้องทำขั้นตอนที่ 3 หนึ่งครั้งเพื่ออนุญาตสิทธิ์ใหม่
