Setup Guide (ระบบคลาวด์ Properties)
  1. 1เปิด script.google.com → คลิก New Project
  2. 2ลบ code เดิมทั้งหมด → Paste code ที่คัดลอก → กด Ctrl+S เพื่อบันทึก
  3. 3เลือกฟังก์ชัน savePDFFromGmail → กด ▶ Run เพื่อทดสอบและอนุญาตสิทธิ์สคริปต์ (Allow Permission)
  4. 4ระบบจะเริ่มบันทึกประวัติแบบถาวรใน Script Properties ทันที โดยไม่สร้างข้อมูลซ้ำ
  5. 5ตั้ง Trigger (ไอคอนนาฬิกาด้านซ้าย) → เลือก savePDFFromGmail → Time-driven → Every hour
  6. 6เสร็จสิ้น! 🎉 แม้คุณจะย้าย/ลบไฟล์ออกจาก Google Drive ทุกสิ้นเดือน ระบบก็จำและไม่โหลดมาซ้ำแน่นอน!
